## 📌 Key Learning Objectives

* **History & Philosophy:** Python was created by Guido van Rossum with the objective of building an open-source, human-readable language that mirrors standard English for daily task automation.


* **Core Elements of Programming Languages:**
* **Alphabet:** Basic symbols used (human: $A–Z$, computer: $0$s and $1$s).


* **Lexis:** Vocabulary or valid keywords (e.g., `print`, `if`, `for`).


* **Syntax:** Grammar rules governing code construction.


* **Semantics:** The underlying meaning and logic behind valid syntax.




## Machine Language vs. High-Level Language:**
* Machine Language: The native binary language (0s and 1s) executed directly by computer hardware. Machine language is natively understood by hardware it is extremely tedious and error-prone for humans to write.



* High level language is the language which is more complex than machine but easily understood by humans. These languages enable humans to express commands to computers that are much more complex than those offered by ILs ( alphabet of machine language).



*To overcome this language barrier of communicating and instructing computers, we use high-Level Languages. High-readable languages enable humans to express commands to computers that are much more complex than those offered by ILs.




*They rely on compilers or interpreters to translate commands for the CPU




* A program written in a high-level programming language is called a source code (in contrast to the machine code executed by computers). Similarly, the file containing the source code is called the source file. High level programming is transformed into machine language in two ways.
(i)Compilation  (ii)Interpretation 


  

## Compilation vs. Interpretation:
* **Compiler:** Translates entire source code into machine code prior to execution.
* **Interpreter:** Translates and executes source code line-by-line during runtime (Python relies on an interpreter).

## 🛠️ Environment Setup & Tooling

### Installation Basics

* **Linux:** Comes pre-installed on most distributions. Verify in terminal using `python3`.


* **Windows:** Download executable installer from python.org. Ensure **"Add Python 3.x to PATH"** is selected during installation.



### Python Development Suite (IDLE)

* **IDLE Shell:** Interactive console to launch, test, or interrupt code execution.


* **Editor Window:** Workspace for writing and saving source code files (e.g., `.py`).


* **Debugger:** Diagnostic tool to trace variable states and step through execution line-by-line.
